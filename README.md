# Boss Constructor Match-3

Конструктор боссов для match-3 боя: настройка, автопроверка баланса, ручной трай и экспорт.

**Сайт:** [Boss Constructor](https://kraupins.github.io/boss_constructor_2/)

## Два режима

### Мастер (Wizard)
Пошаговая настройка как онбординг на телефоне: один вопрос на экран, слева прогресс, справа короткие подсказки. Подходит, если хочешь быстро собрать босса без лишних полей.

### Ручной режим
Тот же функционал, но в удобной оболочке: меню слева (Босс · Генератор · Симуляция · Трай · Итог), настройки в раскрывающихся блоках, без перегруза экрана.

## Что можно сделать

- Задать босса: имя, HP, тип, сложность, игрока.
- Сгенерировать случайного босса по этапу игры (ранний / средний / поздний / финальный).
- Прогнать автосимуляцию и увидеть win rate.
- Сыграть трай — матч-3 против текущего босса в браузере.
- Скопировать итог: текстовый отчёт или JSON.

## Запуск локально

```bash
npm install
npm run dev
```

Открой адрес из терминала (обычно `http://127.0.0.1:5173/`).

```text
src/
  simulator.js           # формулы, матч-3, автобой
  balanceHints.js        # подсказки по балансу
  App.jsx                # режимы и состояние
  components/
    HomeScreen.jsx
    WizardView.jsx       # мастер
    manual/ManualView.jsx
    shared.jsx           # общие UI-элементы
  styles.css
```
